# ESP32-C3 + JK BMS BLE + ST7789 1.9" UI 2.0

## 屏幕接线

- BL = GPIO5
- CS = GPIO3
- DC = GPIO2
- RES = GPIO10
- SDA / MOSI = GPIO7
- SCL / SCK = GPIO6
- 屏幕逻辑分辨率：320x170

### 颜色

- SOC 正常：白色
- SOC ≤ 30%：黄色
- SOC ≤ 15%：红色
- 电压：黄色
- 电流：绿色
- 功率：红色
- 剩余里程：青色
- 温度 / 单体压差：绿色
- 底部电量条：绿色 → 黄色 → 红色

低电量阈值位于 `src/Display.cpp` 顶部，可直接修改。

### 显示内容

左侧：

- SOC 大数字
- 温度
- 单体最高/最低电压差（mV）
- 剩余容量（Ah）

右侧：

- 电池总电压
- 电池总电流
- 功率
- 剩余里程

底部：

- SOC 可视化渐变条

## 刷新方式

主循环每 500ms 检查一次显示数据。

Display 内部继续使用局部 Sprite / 脏区刷新：

- SOC 改变才刷新 SOC 区域；
- 电压改变才刷新电压区域；
- 电流改变才刷新电流区域；
- 功率改变才刷新功率区域；
- 温度、压差或容量改变才刷新左下区域；
- 剩余里程改变才刷新里程区域；
- SOC 改变才刷新底部渐变条。

因此不是每 500ms 整屏刷一次，正常情况下不会产生整屏闪烁。

## 开机连接逻辑

1. 屏幕显示连接电池。
2. 自动扫描 JK / JIKONG / BMS 蓝牙设备。
3. 最多自动扫描 3 次，每次 5 秒。
4. 找到设备后自动连接。
5. 连接成功后进入 UI 2.0 实时仪表盘。
6. 三次都失败后自动进入 Wi-Fi AP 热点模式。

## 热点设置

热点参数：

- SSID：`JK-BMS-SETUP`
- 密码：`12345678`
- 默认网页：`http://192.168.4.1`

手机连接热点后可以：

- 扫描蓝牙 JK BMS；
- 查看设备名称、MAC、RSSI；
- 选择指定电池连接；
- 设置 JK02_24S / JK02_32S；
- 保存 MAC；
- 设置每公里耗电量，用于剩余里程估算。

## BLE

使用 NimBLE-Arduino。

当前 JK BLE 连接：

- Service：`FFE0`
- Characteristic：`FFE1`

连接后发送 JK 查询命令，并接收 `0x02` 主数据帧。
